# Scenario Documentation
## Introduction
This document provides an overview of the scenario system in the AI MultiColony Ecosystem.

## Biomes
The ecosystem features several biomes, each with its own set of resources.

* Desert: low water, moderate food
* Forest: high water, high food
* Ocean: high water, moderate food
* Tundra: low water, low food
* Volcanic: moderate water, moderate food

## Scenarios
Scenarios are predefined combinations of biomes.

* Scenario 1: Desert, Forest
* Scenario 2: Ocean, Tundra
* Scenario 3: Volcanic, Desert

## Environmental Events
The ecosystem is subject to various environmental events.

* Drought: reduces water resources
* Abundance: increases food resources
* Storm: increases water resources

## Configurable Scenario Files
Scenarios can be loaded from YAML or JSON files.

## Example Usage
To load a scenario from a YAML file, use the `load_scenario_from_yaml` function.
